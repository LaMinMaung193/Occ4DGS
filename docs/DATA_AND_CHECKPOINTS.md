# Data and Checkpoints

This document lists every data file and checkpoint required to reproduce this project's results, with expected paths and download sources. Paths below match exactly what the scripts in this project and its companion `GaussianFormer3D` fork expect — if your data lives elsewhere, either recreate this exact path structure or symlink to it.

## 1. Publicly Available Data (download from the original sources)

These are not hosted by this project — download directly from their official sources.

| Item | Source | Expected path |
|---|---|---|
| nuScenes full dataset (v1.0-trainval) | [nuscenes.org/download](https://www.nuscenes.org/download) | `GaussianFormer3D/data/nuscenes/` |
| SurroundOcc occupancy annotations | [SurroundOcc repo](https://github.com/weiyithu/SurroundOcc) | `GaussianFormer3D/data/surroundocc/` |
| GaussianFormer3D's released checkpoint | [GaussianFormer3D repo](https://github.com/NVlabs/GaussianFormer3D) (see its own README's weight links) | `GaussianFormer3D/out/nuscenes_surroundocc_gs25600_full/surroundocc_release.pth` |
| Image backbone pretrained weights | [r101_dcn_fcos3d_pretrain.pth](https://github.com/zhiqi-li/storage/releases/download/v1.0/r101_dcn_fcos3d_pretrain.pth) | `GaussianFormer3D/ckpts/` |

## 2. Derived Data (generated by this project's own scripts)

These are not hosted for download -- generating them yourself is straightforward given the scripts already exist, and their combined size (~13 GB) makes hosting impractical. Run the listed script for each; see [`REPRODUCING_RESULTS.md`](REPRODUCING_RESULTS.md) for exact commands and order.

| File | Size | Generate with |
|---|---|---|
| Depth ground-truth (`depth_gt/`) | ~8.4 GB | `generate_depth_gt_full.py` |
| Dataset info files (`gf3d_infos/*.pkl`) | ~1.6 GB total | GaussianFormer3D's own info-generation tooling + `make_tiered_infos.py`, `make_frame0_infos.py` |
| Stage B pair info + manifest (`stageb_training/nuscenes_infos_gf3d_stageb_pairs_{train,val}.pkl`, `stageb_manifest_{train,val}.json`) | ~670 MB total | `build_stageb_manifest.py` |
| Cached `G_0` (`g0_cache_pretrained_release/`) | ~2.3 GB | `extract_g0_cache.py`, run against `surroundocc_release.pth` |

Expected paths (external drive convention used throughout development):
```
/media/user/1TSSD/min/
├── depth_gt/
├── gf3d_infos/
│   ├── nuscenes_infos_gf3d_train.pkl        (700 infos)
│   ├── nuscenes_infos_gf3d_val.pkl          (150 infos)
│   ├── nuscenes_infos_gf3d_frame0_all.pkl   (850 infos)
│   ├── nuscenes_infos_gf3d_train_small.pkl  (50 infos)
│   ├── nuscenes_infos_gf3d_val_small.pkl    (10 infos)
│   └── nuscenes_infos_gf3d_val_full.pkl     (70 infos)
├── g0_cache_pretrained_release/
└── stageb_training/
    ├── nuscenes_infos_gf3d_stageb_pairs_train.pkl  (651 scene-pairs)

    ├── stageb_manifest_train.json
    └── stageb_manifest_val.json
```

## 4. Verifying Your Setup

Once data is in place, run the quick evaluation commands in the main [`README.md`](../README.md) — an exact `mIoU: 16.75` (do-nothing) and `mIoU: 18.44` (Dynamic Deformation, L=2) confirms everything is correctly set up.
